# Dictionary Flashcard App

Интерактивное приложение для изучения английской лексики на основе спaced-repetition системы (SRS). Приложение использует алгоритм SM-2 для оптимизации расписания повторений слов.

## 📋 Описание

**Dictionary Flashcard** — это полнофункциональное веб-приложение для эффективного пополнения словарного запаса. Оно сочетает классические флэшкарты с передовой техникой интервального повторения для максимальной эффективности обучения.

### Ключевые возможности

- 🎯 **Интеллектуальное повторение (SRS)** — Алгоритм SM-2 автоматически определяет, когда нужно повторить слово
- 📊 **Отслеживание прогресса** — Ведение статистики изучения по каждому слову и категории
- 🎮 **Множество режимов обучения** — Флэшкарты, викторина, просмотр списков
- 📱 **Сенсорные жесты** — Поддержка свайпов для удобства мобильных пользователей
- 💾 **Локальное хранилище** — Все данные сохраняются в браузере, не требуется сервер
- 📈 **Подробная статистика** — Отслеживание серий обучения и общего прогресса
- 🎨 **Современный UI** — Построено на React и Tailwind CSS

## 🛠️ Технологический стек

- **Frontend Framework**: React 19.2
- **Language**: TypeScript 4.9
- **Styling**: Tailwind CSS 3.4
- **State Management**: React Hooks + LocalStorage API
- **Build Tool**: React Scripts 5.0

## 🎯 Основной функционал

### 1. Главная страница (Home Screen)
Центральный хаб приложения, где пользователь может:
- Просмотреть все доступные категории словарей
- Увидеть прогресс по каждой категории (количество изученных слов)
- Получить доступ ко всем основным функциям
- Просмотреть общую статистику и количество слов в SRS для повторения

**Компонент**: `src/screens/HomeScreen.tsx`

### 2. Режим Флэшкарт (Flashcard Screen)
Основной режим изучения слов с использованием интерактивных карточек.

**Возможности**:
- Просмотр слова с транскрипцией и переводом
- Пять режимов обучения:
  - **Обычное обучение** — все слова в категории
  - **Только незнакомые** — повторение только неизученных слов
  - **Перемешанные** — карты показываются в случайном порядке
  - **В обратном порядке** — русский → английский
  - **Комбинированные режимы** — любое сочетание вышеперечисленных
- Сенсорные жесты (свайп) для перемещения между картами
- Отметить слово как "известное" или "неизвестное"
- Просмотр общего прогресса (текущее слово / всего слов)
- Быстрый доступ к следующему слову

**Компонент**: `src/screens/FlashcardScreen.tsx`
**Хук для жестов**: `src/hooks/useSwipe.ts`

### 3. Результаты сессии (Results Screen)
Отображение результатов завершённой сессии обучения.

**Функционал**:
- Список всех слов, просмотренных в сессии
- Статус каждого слова (известное/неизвестное/непросмотренное)
- Процент правильных ответов
- Возможность начать новую сессию
- Кнопка сброса прогресса по категории

**Компонент**: `src/screens/ResultsScreen.tsx`

### 4. Режим SRS (Spaced Repetition Screen)
Специализированный режим для интеллектуального повторения слов на основе алгоритма SM-2.

**Характеристики**:
- Показывает только слова, которые нужно повторить сегодня
- Использует SM-2 алгоритм для динамического расписания повторений
- Оценка сложности слова (0-5 баллов)
- Автоматическое обновление интервала повторения в зависимости от оценки
- Визуальный индикатор дней до следующего повторения
- Отслеживание количества успешных повторений

**Компонент**: `src/screens/SRSScreen.tsx`
**Утилиты**: `src/utils/srs.ts`

### 5. Викторина (Quiz Screen)
Интерактивный режим с вопросами с множественным выбором.

**Функционал**:
- 4 варианта ответов на каждый вопрос
- Пояснение правильного ответа
- Подсчёт правильных/неправильных ответов
- Поддержка всех режимов обучения (только неизвестные, перемешанные и т.д.)

**Компонент**: `src/screens/QuizScreen.tsx`

### 6. Список слов (Word List Screen)
Просмотр всех слов в выбранной категории в формате таблицы/списка.

**Возможности**:
- Полный список всех слов категории
- Отображение статуса каждого слова (известное/неизвестное/непросмотренное)
- Быстрый поиск и фильтрация
- Просмотр транскрипции и перевода

**Компонент**: `src/screens/WordListScreen.tsx`

### 7. Статистика (Stats Screen)
Подробное отображение статистики обучения.

**Показатели**:
- Общее количество изученных слов
- Процент изученности по каждой категории
- Дневная серия обучения (streak)
- Дата последнего изучения
- Общее распределение слов по статусам
- SRS статистика (количество слов для повторения, среднее количество повторений)

**Компонент**: `src/screens/StatsScreen.tsx`

## 💾 Архитектура и структура данных

### Основные типы данных

#### Word (Слово)
```typescript
interface Word {
  english: string;        // английское слово
  transcription: string;  // британская транскрипция
  russian: string;        // русский перевод
}
```

#### Category (Категория)
```typescript
interface Category {
  id: number;
  name: string;
  words: Word[];
}
```

#### Progress (Прогресс изучения)
```typescript
type WordStatus = 'known' | 'unknown' | 'unseen';

interface CategoryProgress {
  [wordIndex: number]: WordStatus;  // статус каждого слова в категории
}

interface Progress {
  [categoryId: number]: CategoryProgress;  // прогресс по категориям
}
```

#### SRS Card (SM-2 Карта)
```typescript
interface SRSCard {
  interval: number;      // дней до следующего повторения
  repetitions: number;   // количество успешных повторений подряд
  easeFactor: number;    // коэффициент сложности (мин. 1.3, макс. неограниченный)
  nextReview: string;    // дата следующего повторения (YYYY-MM-DD)
}
```

#### App Storage (Основное хранилище)
```typescript
interface AppStorage {
  progress: Progress;           // статус изучения слов
  difficulty: DifficultyRecord; // сложность слов
  lastStudied: string | null;   // дата последнего обучения
  streakDays: number;           // количество дней подряд обучения
  streakLastDate: string | null; // дата последнего дня серии
  srs: SRSData;                 // SRS данные всех слов
}
```

## 🧠 Алгоритм SRS (SM-2)

Приложение использует **алгоритм SM-2** (SuperMemo-2) для оптимального расписания повторений.

### Как это работает

1. **Начальное создание карточки**
   - Интервал: 1 день
   - Коэффициент сложности (easeFactor): 2.5 (по умолчанию)
   - Количество повторений: 0

2. **Оценка качества ответа** (0-5 баллов)
   - **0-2**: Неправильный ответ → сброс интервала на 1 день
   - **3-5**: Правильный ответ → увеличение интервала

3. **Расчёт нового интервала**
   - 1-е успешное повторение: 1 день
   - 2-е успешное повторение: 6 дней
   - Последующие: `интервал × коэффициент сложности`

4. **Обновление коэффициента сложности**
   ```
   easeFactor = max(1.3, easeFactor + 0.1 - (5 - quality) × (0.08 + (5 - quality) × 0.02))
   ```
   - Точный ответ → коэффициент увеличивается
   - Неточный ответ → коэффициент уменьшается
   - Минимальное значение: 1.3

### Пример
- День 1: Изучено слово, оценка 5 → интервал 1 день
- День 2: Повторение, оценка 4 → интервал 6 дней
- День 8: Повторение, оценка 5 → интервал 15 дней
- День 23: Повторение, оценка 3 → интервал 37 дней

## 📱 Сенсорные жесты

- Статистика SRS для каждой карточки
- История обучения (дата последнего обучения, серия дней)
- Информация о сложности слов

**Управление хранилищем**: `src/hooks/useStorage.ts`

## 📊 Использование

### Стандартный рабочий процесс

1. **Откройте приложение** → Перейдите на главную страницу
2. **Выберите категорию** → Кликните на категорию из списка
3. **Выберите режим обучения** → Флэшкарты, викторина или SRS
4. **Учитесь** → Проходите слова и отмечайте известные/неизвестные
5. **Проверьте результаты** → Просмотрите статистику сессии
6. **Повторяйте регулярно** → Используйте SRS для эффективного повторения

### Советы для эффективного обучения

- 📅 **Регулярность**: Обучайтесь каждый день для максимальной эффективности
- 🎯 **SRS режим**: Используйте режим SRS для фокусированного повторения слов для повторения
- 📊 **Отслеживайте прогресс**: Регулярно проверяйте статистику, чтобы видеть улучшения
- 🔄 **Комбинируйте режимы**: Чередуйте флэшкарты и викторину для разнообразия

## 🐛 Устранение неполадок

### Данные не сохраняются
- Проверьте, что LocalStorage включён в браузере
- Проверьте, хватает ли свободного места
- Очистите кеш браузера и перезагрузите приложение

### Слова не показываются
- Убедитесь, что файл `vocabulary.json` на месте
- Проверьте консоль браузера на наличие ошибок
- Перезагрузите страницу
